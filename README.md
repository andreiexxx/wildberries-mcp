# Wildberries для Claude

Подключите свой кабинет Wildberries к Claude и спрашивайте про продажи, рекламу и отзывы обычными словами. Установка займёт 5–7 минут, программировать не нужно.

> **Вы сейчас на GitHub.** Это сайт, где хранят код программ. Регистрироваться здесь не нужно: от вас требуется только скачать один файл по кнопке ниже и пройти шаги из этой инструкции.

## ⬇️ [Скачать расширение — wildberries.mcpb](https://github.com/andreiexxx/wildberries-mcp/releases/latest/download/wildberries.mcpb)

---

## Коротко, если торопитесь

1. Поставьте приложение Claude для компьютера: [claude.ai/download](https://claude.ai/download).
2. В кабинете WB создайте **персональный токен**: [Интеграции по API](https://seller.wildberries.ru/api-integrations) → «+ Создать токен».
3. Скачайте [wildberries.mcpb](https://github.com/andreiexxx/wildberries-mcp/releases/latest/download/wildberries.mcpb) и дважды кликните по файлу.
4. В окне установки вставьте токен, сохраните, перезапустите Claude и напишите: «Проверь подключение к Wildberries».

Если что-то непонятно — ниже каждый шаг расписан подробно.

## Что умеет

| Спросите Claude | Что он сделает |
|---|---|
| «Сколько я продал за прошлую неделю?» | Посчитает продажи, возвраты и сумму к перечислению |
| «Какой ДРР по рекламным кампаниям за 7 дней?» | Покажет по каждой кампании расход, заказы, выручку и ДРР |
| «Какие кампании тратят деньги, но не приносят заказов?» | Найдёт кампании с расходом и нулём заказов |
| «Сколько денег на рекламном счёте?» | Покажет счёт и баланс |
| «Покажи отзывы без ответа и предложи ответы» | Выгрузит отзывы и напишет черновики ответов |
| «На каком шаге теряются покупатели в карточке 123456789?» | Разберёт воронку: переходы → корзина → заказ → выкуп |
| «Что заканчивается на складах?» | Посмотрит остатки |
| «Поставь ставку 350 ₽ в кампании 12345678» | Изменит ставку — **только если вы разрешили изменения** |

## Что понадобится

- **Компьютер на macOS или Windows.** В браузере и на телефоне расширение не работает: оно живёт внутри приложения Claude на компьютере.
- **Приложение Claude для компьютера** последней версии.
- **Доступ владельца к кабинету продавца WB.** Токены может создавать только владелец кабинета.

## Установка по шагам

### Шаг 1. Установите приложение Claude

1. Откройте [claude.ai/download](https://claude.ai/download).
2. Скачайте версию для своего компьютера (Mac или Windows) и установите, как обычную программу.
3. Запустите Claude и войдите в свой аккаунт.

> Приложение уже стоит? Обновите его до последней версии: в старых версиях нет установки расширений.

Интерфейс Claude на английском, поэтому ниже названия кнопок написаны так, как они выглядят на экране, а в скобках — перевод.

### Шаг 2. Создайте токен в кабинете WB

Токен — это ключ, по которому Claude сможет получать данные вашего магазина. Что-то вроде пароля, только для программ.

1. Откройте кабинет продавца и перейдите в раздел **«Интеграции по API»**: [seller.wildberries.ru/api-integrations](https://seller.wildberries.ru/api-integrations).
   Если ссылка не открылась — нажмите на название организации в правом верхнем углу кабинета и выберите «Интеграции по API».
2. Нажмите **«+ Создать токен»**.
3. Переключитесь на вкладку **«Для интеграции вручную»** и выберите **«Персональный токен»**.
   WB покажет предупреждение, что такой токен нельзя использовать в облачных сервисах. Это нормально: расширение работает у вас на компьютере, а не в облаке.
4. **Название** — любое понятное, например «Claude на моём компьютере».
5. **Категории** — отметьте галочками:

   | Категория | Что с ней сможет Claude |
   |---|---|
   | Статистика | Продажи и возвраты |
   | Аналитика | Воронка карточек и остатки на складах |
   | Контент | Список ваших товаров |
   | Продвижение | Реклама, расходы, ДРР, ставки, пауза кампаний |
   | Вопросы и отзывы | Отзывы и вопросы покупателей |
   | Цены и скидки | Изменение цен |

6. **Уровень доступа:**
   - **«Только чтение»** — Claude сможет только смотреть данные. **Советуем начать с этого.**
   - **«Чтение и запись»** — выберите, если хотите, чтобы Claude мог менять ставки и цены.
7. Отметьте согласие **«Я понимаю, что не следует передавать токен третьим лицам»**.
8. Нажмите **«Создать»**, а затем **«Скопировать и закрыть»**. Токен окажется в буфере обмена.

> ⚠️ **WB показывает токен только один раз.** Сразу переходите к шагам 3–4 и вставьте его в Claude. Если потеряли — удалите этот токен в кабинете и создайте новый, это займёт минуту.
>
> 🔒 **Никому не отправляйте токен:** ни в чат, ни в поддержку, ни автору этого расширения. Вставлять его нужно только в окно настроек Claude.

### Шаг 3. Скачайте расширение

Нажмите: **[⬇️ Скачать wildberries.mcpb](https://github.com/andreiexxx/wildberries-mcp/releases/latest/download/wildberries.mcpb)**

Файл сохранится в папку «Загрузки». Если браузер спросит, сохранить файл или нет, — выберите «Сохранить». Весь код расширения открыт и лежит на этой странице в папке [`server`](server/index.js).

### Шаг 4. Установите расширение в Claude

**Способ А — двойной клик (проще всего).**
Откройте папку «Загрузки» и дважды кликните по файлу `wildberries.mcpb`. Откроется Claude с окном установки.

**Способ Б — через настройки (если двойной клик не сработал).**
1. В Claude откройте **Settings** (Настройки). На Mac: меню Claude в левом верхнем углу экрана → Settings. На Windows: меню ☰ или значок профиля → Settings.
2. Перейдите в раздел **Extensions** (Расширения).
3. Нажмите **Advanced settings** (Расширенные настройки) и в блоке **Extension Developer** нажмите **Install Extension…** (Установить расширение).
4. Выберите файл `wildberries.mcpb` в папке «Загрузки».

Можно ещё просто перетащить файл мышкой в окно Claude.

**Дальше в окне установки:**
1. Нажмите **Install** (Установить).
2. В поле **«Токен WB API»** вставьте токен: `Cmd + V` на Mac или `Ctrl + V` на Windows.
3. Галочку **«Разрешить изменения»** пока не трогайте — про неё [ниже](#изменение-ставок-и-цен).
4. Сохраните настройки и проверьте, что у расширения Wildberries включён переключатель (**Enabled**).

### Шаг 5. Проверьте, что всё работает

1. **Полностью перезапустите Claude.** На Mac: `Cmd + Q`, затем откройте снова. На Windows: закройте окно, найдите значок Claude возле часов, нажмите на него правой кнопкой и выберите Quit, затем откройте снова.
2. Откройте **новый чат** и напишите: **«Проверь подключение к Wildberries»**.
3. Claude спросит разрешение воспользоваться инструментом — нажмите **Allow** (Разрешить). Чтобы он не спрашивал каждый раз, выберите «Always allow» (Разрешать всегда).
4. Если в ответе есть «WB принял токен, всё работает» — готово 🎉

## Что спросить у Claude

**Продажи и остатки**
- «Сравни продажи этой недели с прошлой»
- «Сколько было возвратов за сентябрь и на какую сумму?»
- «Какие товары заканчиваются на складах WB?»

**Реклама**
- «Покажи ДРР по всем кампаниям за 14 дней, отсортируй от худшего»
- «Какие кампании за неделю потратили больше 3000 ₽ без единого заказа?»
- «Сколько осталось на рекламном счёте и на сколько дней его хватит при текущем расходе?»

**Карточки и воронка**
- «Разбери воронку по моим топ-5 товарам: где теряются покупатели?»
- «У каких карточек много переходов, но мало добавлений в корзину?»

**Отзывы и вопросы**
- «Покажи отзывы на 1–3 звезды без ответа и напиши вежливые ответы»
- «О чём чаще всего спрашивают покупатели?»

> Если у вас есть скиллы для Claude по Wildberries, они тоже смогут брать данные отсюда — токен вводить ещё раз не нужно.

## Изменение ставок и цен

По умолчанию расширение **только читает** данные. Менять ставки, ставить кампании на паузу и менять цены оно начнёт, только если выполнены оба условия:

1. Токен создан с уровнем доступа **«Чтение и запись»**.
2. В настройках расширения включена галочка **«Разрешить изменения»**: Settings → Extensions → Wildberries → **Configure** (Настроить) → «Разрешить изменения» → сохранить.

**Предохранители** — они встроены в код, отключить их нельзя:
- ставка — не выше **5 000 ₽**;
- цена за один раз меняется **не больше чем на 50 %** — защита от случайно лишнего или потерянного нуля;
- перед каждым изменением Claude спрашивает разрешение, а вы видите, что именно он собирается сделать.

> 💡 Хороший порядок работы: сначала «покажи, какие ставки ты бы поменял и почему», проверить — и только потом «делай».

## Безопасность

- **Где хранится токен.** В защищённом хранилище вашего компьютера: «Связка ключей» на Mac, «Диспетчер учётных данных» на Windows. В файлах он не лежит.
- **Куда уходит токен.** Только на серверы Wildberries (`*.wildberries.ru`). Других адресов в коде нет, это можно проверить в файле [`server/index.js`](server/index.js).
- **Кто видит токен.** Никто, кроме вашего компьютера и Wildberries. Автор расширения его не получает.
- **Какие данные видит Claude.** Только те, о которых вы спрашиваете в чате, — так же, как если бы вы скопировали таблицу из кабинета и вставили её в Claude.
- **Срок действия.** Токен WB живёт 180 дней. Потом создайте новый и замените его в настройках расширения (Configure).
- **Перестали пользоваться?** Удалите токен в кабинете WB в разделе «Интеграции по API».

Это неофициальное расширение: оно не связано ни с Wildberries, ни с Anthropic.

## Если что-то не работает

**Двойной клик по файлу ничего не делает.**
Обновите Claude до последней версии и установите расширение способом Б — через Settings → Extensions → Advanced settings → Install Extension…

**Claude отвечает, что не видит инструменты Wildberries.**
1. Полностью перезапустите Claude (см. шаг 5).
2. Settings → Extensions: проверьте, что переключатель у Wildberries включён.
3. Откройте новый чат — в старых чатах инструменты могут не появиться.
4. Нажмите «+» внизу поля ввода сообщения → **Connectors** и проверьте, что Wildberries включён.
5. В некоторых версиях Claude расширения работают в обычном чате, но не в Cowork, или наоборот. Обновите Claude. Если не помогло — используйте [способ без расширения](#без-расширения-через-файл-настроек).

**«WB не принял токен».**
Токен истёк, удалён или скопирован не целиком. Создайте новый (шаг 2), затем Settings → Extensions → Wildberries → Configure → вставьте новый токен → сохраните.

**«У токена нет доступа к этому разделу».**
При создании токена не отмечена нужная категория — проверьте по таблице в шаге 2. Добавить категорию в готовый токен нельзя, нужно создать новый.

**«WB временно ограничил частоту запросов».**
У WB есть лимиты: например, статистику рекламы можно запрашивать примерно раз в минуту. Подождите минуту и повторите.

**«Не удалось связаться с WB».**
Проверьте интернет. Если включён VPN, добавьте сайты `wildberries.ru` в исключения или ненадолго его выключите.

**Изменения не проходят.**
Проверьте оба условия из раздела [«Изменение ставок и цен»](#изменение-ставок-и-цен): токен «Чтение и запись» и включённая галочка.

**У меня несколько кабинетов.**
Одно расширение работает с одним токеном. Для нескольких кабинетов используйте [способ без расширения](#без-расширения-через-файл-настроек) и добавьте каждый кабинет отдельной записью.

**Как обновить расширение.**
Скачайте файл по той же ссылке и установите его так же, как в первый раз. Если после обновления Claude попросит токен ещё раз — вставьте новый.

**Как удалить.**
Settings → Extensions → Wildberries → Uninstall. Затем удалите токен в кабинете WB.

**Где посмотреть логи.**
Mac: папка `~/Library/Logs/Claude/`. Windows: `%APPDATA%\Claude\logs`. Файл с `Wildberries` в названии. В лог записывается каждое изменение ставок и цен; токен туда не пишется.

## Для продвинутых

### На свой сервер — для claude.ai, телефона и Codex

Расширение работает, пока открыт Claude на вашем компьютере. Если нужен
доступ отовсюду — с телефона, из браузера, из Codex, — поставьте этот же
сервер на свой VPS. Те же 13 инструментов, только по адресу в интернете.

Нужно: VPS на Ubuntu 22.04 или 24.04, домен (или бесплатный поддомен
duckdns.org), смотрящий на IP сервера, и токен WB.

```bash
git clone https://github.com/andreiexxx/wildberries-mcp.git wb-mcp
cd wb-mcp
sudo bash install.sh
```

Установщик спросит домен и токен, сам поставит Docker, получит сертификат
HTTPS и напечатает адрес вида `https://ваш-домен/mcp?key=СЕКРЕТ`.
Этот адрес — ключ доступа, не пересылайте его.

Подключение:

- **Claude** (приложение или claude.ai): Настройки → Connectors → Add custom
  connector → вставить адрес → Add. Поля OAuth оставить пустыми.
- **Claude Code:** `claude mcp add --transport http wildberries "АДРЕС"`
- **Codex:** `codex mcp add wildberries --url "АДРЕС"`

Изменения на сервере **выключены**. Включаются строкой `WB_ALLOW_WRITE=true`
в файле `.env` и командой `docker compose up -d`. Учтите: тогда менять
ставки и цены сможет любой, у кого есть адрес коннектора.

Обслуживание — из папки `wb-mcp`:

| Задача | Команда |
|---|---|
| Показать адрес ещё раз | `sudo bash install.sh url` |
| Обновить | `sudo bash install.sh update` |
| Логи | `docker compose logs -f wb-mcp` |
| Сменить токен или секрет | поправить `.env`, затем `docker compose up -d` |

Защита: без секрета сервер отвечает 401, запросы не на ваш домен отклоняются,
адреса запросов не пишутся в журнал, наружу открыт только HTTPS через Caddy.


### Claude Code

Нужен Node.js 18 или новее.

```bash
git clone https://github.com/andreiexxx/wildberries-mcp.git
claude mcp add wildberries --scope user --env WB_TOKEN=ВАШ_ТОКЕН -- node "$(pwd)/wildberries-mcp/server/index.js"
```

Чтобы разрешить изменения, добавьте `--env WB_ALLOW_WRITE=true`. Учтите: в этом варианте токен хранится в настройках Claude Code открытым текстом.

### Без расширения, через файл настроек

Нужен Node.js 18 или новее: [nodejs.org](https://nodejs.org). Способ подходит и для нескольких кабинетов.

1. Скачайте код: зелёная кнопка **Code** вверху этой страницы → **Download ZIP** → распакуйте, например, в папку «Документы».
2. В Claude: Settings → **Developer** (Для разработчиков) → **Edit Config** (Изменить настройки). Откроется файл `claude_desktop_config.json`.
3. Впишите в него (пути и токены — свои):

```json
{
  "mcpServers": {
    "wb-kabinet-1": {
      "command": "node",
      "args": ["/Users/имя/Documents/wildberries-mcp-main/server/index.js"],
      "env": { "WB_TOKEN": "ТОКЕН_ПЕРВОГО_КАБИНЕТА" }
    },
    "wb-kabinet-2": {
      "command": "node",
      "args": ["/Users/имя/Documents/wildberries-mcp-main/server/index.js"],
      "env": { "WB_TOKEN": "ТОКЕН_ВТОРОГО_КАБИНЕТА", "WB_ALLOW_WRITE": "true" }
    }
  }
}
```

На Windows путь пишется так: `"C:\\Users\\имя\\Documents\\wildberries-mcp-main\\server\\index.js"`.

4. Сохраните файл и полностью перезапустите Claude.

В этом варианте токены лежат в файле открытым текстом — никому не пересылайте этот файл.

### Инструменты

| Инструмент | Что делает | Меняет магазин |
|---|---|---|
| `wb_check` | Проверка токена и подключения | нет |
| `wb_sales` | Продажи и возвраты за период | нет |
| `wb_stocks` | Остатки на складах WB | нет |
| `wb_products` | Карточки товаров | нет |
| `wb_ad_balance` | Баланс рекламного счёта | нет |
| `wb_campaigns` | Рекламные кампании | нет |
| `wb_ad_stats` | Статистика рекламы и ДРР | нет |
| `wb_reviews` | Отзывы покупателей | нет |
| `wb_questions` | Вопросы покупателей | нет |
| `wb_funnel` | Воронка по карточкам | нет |
| `wb_set_bid` | Изменить ставку | **да** |
| `wb_campaign_state` | Пауза или запуск кампании | **да** |
| `wb_set_price` | Изменить цену | **да** |

### Как устроено

- `server/index.js` — весь сервер, без внешних зависимостей. Работает по протоколу MCP через stdio.
- `manifest.json` — описание расширения для Claude.
- Собрать файл расширения: `npx @anthropic-ai/mcpb pack . dist/wildberries.mcpb`.
